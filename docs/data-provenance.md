# 추첨 결과 데이터 출처

`app/src/main/assets/draws.json`은 앱의 오프라인 초기 데이터다. 2026-09-18에 동행복권의 로또 6/45 회차별 당첨번호 화면과 그 화면이 직접 호출하는 조회 API에서 수집했다.

- 공식 화면: <https://www.dhlottery.co.kr/lt645/result>
- 공식 조회 API: <https://www.dhlottery.co.kr/lt645/selectPstLt645InfoNew.do>
- 포함 범위: 1회(2002-12-07)부터 1241회(2026-09-12)까지 1,241건
- 검증: 회차 연속성, 회차 중복·충돌, 날짜 형식 및 매주 토요일 7일 간격, 오름차순 본번호 6개의 1~45 범위·고유성, 보너스 번호의 범위·비중복
- 재현: 저장소 루트에서 `python scripts/update-draws.py` 실행

각 레코드의 `source`는 해당 회차를 여는 공식 결과 화면 URL이다. `draws-manifest.json`에는 검증일, 범위, 건수, 조회 API와 `draws.json`의 SHA-256을 기록한다. 앱은 이 네트워크 주소를 실행 중 의존하지 않고 APK에 포함된 JSON만 읽는다.

동행복권 사이트의 공개 당첨번호는 사실 데이터지만, 사이트에서 대량 재배포를 명시적으로 허용하는 별도 오픈 라이선스는 확인하지 못했다. 따라서 이 저장소가 외부 공개·배포되기 전에는 동행복권의 이용약관과 데이터 재배포 허용 범위를 별도로 확인해야 한다. 이 파일은 저작권 또는 재배포 허가를 보증하지 않는다.
