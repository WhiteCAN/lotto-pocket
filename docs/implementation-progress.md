## 구현 판단 및 계획 차이

- CameraX 전용 화면 대신 시스템 카메라의 전체 해상도 촬영을 사용한다. 앱이 카메라 권한을 직접 요청하지 않으며 시스템 촬영 앱의 권한/취소 흐름을 따른다.
- 사전 생성 SQLite 파일 대신 내장 JSON을 첫 실행에 검증해 Room으로 적재한다. 이후 앱은 내부 DB로 동작한다.
- 구매 게임은 회차+번호로 중복 제거한다. 원본 용지 일련번호와 같은 조합의 복수 구매 수량은 첫 버전에서 추적하지 않는다.
- OCR은 인식한 행을 검수하는 방식이며 글자별 신뢰도 강조는 구현하지 않았다.
- 추천 기록의 옵션 JSON에는 통계 기준 회차와 원본 구매 기록 ID를 저장한다.
- 백업은 내보내기·가져오기 모두 5MB 제한을 적용한다. 옵션이 없는 백업은 현재 설정을 보존한다.
- 큰 후보 공간에서도 조합을 전수 생성하지 않고 조합 순위에서 균등 선택한다.
- 실제 기기가 없으므로 인식 정확도와 기기별 접근성·설치 검증은 완료로 처리하지 않는다. UI 확인은 Robolectric 360dp이며 전체 크기/글꼴 조합 검증은 남아 있다.

원래 계획의 개별 파일명과 체크박스는 설계 당시 기준이다. 실제 통합 구현과 완료 범위는 이 문서를 기준으로 확인한다.
