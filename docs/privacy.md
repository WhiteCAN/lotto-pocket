# 개인 정보와 저장 방식

로또 포켓은 회원가입, 광고 SDK, 분석 SDK, 네트워크 통신, 복권 구매 기능이 없습니다. Android INTERNET 권한을 선언하지 않습니다.

구매·추천번호, 고정번호, 추천 조건, 당첨 결과는 앱 전용 SQLite(Room) DB에 저장됩니다. 앱 삭제 시 함께 삭제되며 Android 자동 백업은 사용하지 않습니다. 데이터 관리 화면에서 JSON 파일로 직접 백업·복원할 수 있습니다. 이 파일에는 개인 구매 기록이 들어 있으므로 공유할 때 내용을 확인하세요.

QR·사진 인식 모델은 앱에 포함되어 기기에서 처리됩니다. 사진은 외부 서버로 전송하지 않습니다. 시스템 카메라 촬영 임시 파일은 인식 완료·취소 시 삭제합니다. 앱이 비정상 종료되었을 경우 캐시가 남을 수 있고 Android가 캐시를 정리하거나 앱 삭제 시 제거됩니다. 사진 선택기는 사용자가 선택한 사진만 앱에 전달합니다.

생일·기념일은 월·일을 1~45의 고정번호로 변환하며 연도나 전체 생년월일을 보관하지 않습니다.

공통 당첨번호 데이터 출처와 기준 회차는 data-provenance.md 및 앱 데이터 관리에서 확인할 수 있습니다.
