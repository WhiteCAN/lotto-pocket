# UI·UX 수정 — 2026-10-05

실기기 점검에서 확인한 네 가지 문제를 수정했다.

- 추천 결과가 있으면 상단 소개·회차·조건 카드를 간단한 제목으로 대체하고 첫 게임으로 이동한다. 결과 화면의 등록·설정·회차 변경은 하단 보조 시트로 모았다. 저장·다시 뽑기·번호 잠금은 하단에서 유지한다.
- 추천 설정은 본문만 스크롤하고 설정 적용 버튼은 시트 하단에 둔다. 키보드 영역은 IME inset으로 반영한다.
- 빈 생일은 ‘월과 일을 모두 입력해 주세요.’를 월·일 바로 아래에 표시한다. 잘못된 날짜도 도메인의 한국어 안내를 사용한다.
- 고정번호는 숫자 키패드를 요청하고 구분 공백 버튼을 제공한다. 버튼 사용 시 커서를 맨 끝으로 이동해 다음 숫자가 앞 번호에 붙지 않게 한다.

검증: testDebugUnitTest 36개 통과, lintDebug 및 assembleDebug 성공. 날짜 입력 오류, 빈도 옵션 확장 후 적용 버튼 표시, 공백 버튼을 사용한 7·21 입력과 화면 회전 후 보존을 UI 테스트로 확인했다.

수정 debug APK를 SM-S938N에 덮어설치하고 cold start 성공(518ms). 잠금 해제 후 실기기 확인까지 완료했다. 2배 글꼴에서 A·B게임 전체와 C게임 번호가 첫 화면에 보였다. 숫자 키패드와 키보드 위 적용 버튼, 빈도 옵션 확장 상태의 적용 버튼, 월·일 바로 아래 한국어 오류를 확인했다. 글꼴을 원래 0.8배로 복원했고 추천 저장·설정 적용은 실행하지 않았다. 캡처: app/build/reports/ux-device-audit/fixed-*.png.

보고서의 초안 보호·제외/복원 상세·전체 테마 통일 등 추가 제안은 이번 네 가지 수정에 포함하지 않았다. 기존 미커밋 작업을 유지했다.
