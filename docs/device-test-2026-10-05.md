## 발견·수정

고정번호가 2개일 때 가중치 배치가 번호 공을 행 너비의 절반까지 확대했다. 번호 행에 남은 6칸의 빈 공간을 유지하도록 수정했다. 실제 화면에서 고정번호 요약의 높이가 약 398px 줄고, 일반 6번호 표시와 공 크기가 같아짐을 확인했다. 수정 APK를 기기에 설치했다.

수정 후 `testDebugUnitTest`, `lintDebug`, `assembleDebug` 성공. 기존 35개 자동 테스트 통과. 추가 테스트 코드를 늘리는 대신 해당 레이아웃의 실기기 화면을 확인했다. 로컬 증거는 `app/build/reports/device-test/`에 있으며 기기 DB 복사본을 포함하므로 Git에 넣지 않는다.
