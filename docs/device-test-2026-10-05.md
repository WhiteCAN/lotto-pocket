## 발견·수정

고정번호가 2개일 때 가중치 배치가 번호 공을 행 너비의 절반까지 확대했다. 번호 행에 남은 6칸의 빈 공간을 유지하도록 수정했다. 실제 화면에서 고정번호 요약의 높이가 약 398px 줄고, 일반 6번호 표시와 공 크기가 같아짐을 확인했다. 수정 APK를 기기에 설치했다.

수정 후 `testDebugUnitTest`, `lintDebug`, `assembleDebug` 성공. 기존 35개 자동 테스트 통과. 추가 테스트 코드를 늘리는 대신 해당 레이아웃의 실기기 화면을 확인했다. 로컬 증거는 `app/build/reports/device-test/`에 있으며 기기 DB 복사본을 포함하므로 Git에 넣지 않는다.

## 삭제·초기화 기능 업데이트 확인

- 같은 Galaxy S25 Ultra에 `adb install -r`로 추가 기능 APK를 설치했고 Success를 확인했다.
- 내 로또의 개별 기록 삭제, 기록 관리의 회차 미구매 추천 삭제, 백업·전체 초기화의 전체 개인 기록 초기화 확인창과 취소 동작을 확인했다. 확인창에서 대상 건수와 보존 범위를 표시한다.
- 실제 기기에서는 삭제·초기화를 확정하지 않았다. 설치 전과 확인창 취소 후 DB를 비교해 games 3행, settings 1행, draws 1,241행의 각 전체 내용 SHA-256이 동일함을 확인했다.
- 삭제 실행·구매 표시 기록 보존·삭제 후 재추천·초기화 후 당첨 데이터 보존은 격리된 Room/Compose 자동 테스트로 검증했다. 총 38개 테스트 통과, Debug/Release 빌드 성공, lint 오류 0개·경고 14개.
- 로컬 DB 비교 자료와 UI 확인 도구는 `app/build/reports/device-delete-test/`에 보관하며 Git에 포함하지 않는다.

## 추천 설정 스크롤 안정화 확인

- 추천 설정에서 시트 드래그를 끄고 내용만 스크롤하도록 변경했다. 드래그 핸들 대신 닫기 버튼을 제공하며 바깥 영역·뒤로가기로 닫는 동작은 유지한다.
- Galaxy S25 Ultra에 수정 APK를 덮어설치했다. 기본 상태의 위로 스와이프 3회, 빈도 옵션을 펼친 상태의 위·아래 스와이프 3회에서 제목과 적용 버튼 좌표가 일정했다. 키보드가 열린 상태에서도 스크롤 전후 좌표가 일정하고 적용 버튼이 표시됐다. 설정을 적용하지 않고 닫았다.
- 회귀 테스트는 드래그 도중 제목 위치와 스크롤 양 끝의 내용·적용 버튼을 검사한다. 시트 드래그를 다시 켜면 제목 위치 검사에서 실패하고, 끄면 통과함을 확인했다.
- 실기기 좌표 비교는 제스처 전후의 안정성을 확인한 것으로 모든 프레임의 떨림이 없음을 증명하지는 않는다. 로컬 근거는 `app/build/reports/scroll-check/`에 보관한다.
- 수정본 설치 후 사용자가 직접 스크롤하여 떨림이 사라진 것 같다고 확인했다. 이 수정을 Preview 4에 포함한다.

## 범위와 남은 확인

- 선명한 생성 이미지의 OCR 성공은 실제 종이·흐림·기울어진 사진의 인식 정확도 검증을 대신하지 않는다.
- 실제 로또 QR 촬영 후 해석, 비행기 모드 최초 설치, TalkBack, 전체 글꼴/화면 크기 조합은 미검증이다.
- 당첨 데이터는 여전히 1~1241회다. 1242회 이후 결과 갱신은 이번 폰 테스트 범위에 포함하지 않았다.
- 휴대폰에는 테스트한 미구매 추천 3게임과 고정 7·21/3게임 설정이 남아 있다. 실제 구매로 표시한 항목은 없다.
